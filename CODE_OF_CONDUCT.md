# Code of Conduct

Gunny Red is loud, but this project is welcoming. The character is tough *for laughs and motivation* — the community around it is not.

## The short version

- Be respectful. Critique code, not people.
- No harassment, discrimination, or hate — of any kind, toward anyone.
- Assume good faith. Disagree without being a jerk.
- Keep contributions in good taste. "Drill instructor" is the bit; bigotry and cruelty are not.

## Scope

This applies to all project spaces — issues, pull requests, discussions — and to public spaces when representing the project.

## Enforcement

Violations can be reported to the maintainer via a GitHub issue or direct contact. Maintainers may remove, edit, or reject contributions and comments that violate this code, and may ban repeat or serious offenders.

This is a lightweight adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/). Be the kind of recruit Gunny would actually be proud of.
